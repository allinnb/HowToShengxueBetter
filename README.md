# 高性价比升学指南

花掉什么、换回什么、证据有多硬 —— 每个升学决策都算一笔账。

方法论致敬《高性价比人生指南》(eternity4719/HowToLiveBetter)。

## 在线看

GitHub Pages 开启后：`https://<你的用户名>.github.io/<仓库名>/`

支持链接直达筛选，例如：`?ratio=极高`、`?cat=升学路径`、`?q=复读`、`?sec=留学`

## 一站三库：升学 / 留学 / 移民

同一个网站、同一套工作流，条目编号前缀决定板块：

| 前缀 | 板块 | 模板 |
|------|------|------|
| `LS-` | 升学 | 照 `entries/LS-001.md` 的格式 |
| `LX-` | 留学 | `templates/LX-留学条目模板.md` |
| `YM-` | 移民 | `templates/YM-移民条目模板.md` |

LX/YM 条目在通用字段之外多了两个**必填**字段：`国家/项目:`（如"新西兰·技术移民 SMC"）和`政策时效:`（如"截至 2026-09 核验"）；合规红线是"包过签/包移民/包录取"类话术一律写成骗局。导航栏的"升学 / 留学 / 移民"分区和 `?sec=` 直达链接由 `build.py` 按编号前缀自动生成。

## 自己编辑条目（网页端，不用懂代码）

能。直接在 GitHub 网页上操作：

1. 打开仓库 → `entries/` 文件夹 → 点开要改的条目（如 `LS-004.md`）→ 右上角铅笔图标 ✏️ 编辑
2. 新增条目：`entries/` 里点 "Add file" → "Create new file"，文件名 `LS-025.md`（升学）/`LX-001.md`（留学，照 `templates/` 下对应模板填）/`YM-001.md`（移民），内容照着模板的格式抄
3. 删除条目：点开文件 → 右上角 "…" → "Delete file"
4. 点绿色 "Commit changes" 保存

保存后 GitHub Actions 会自动运行 `build.py` 重新生成网站，1–2 分钟后页面自动更新，**不用手动跑任何命令**。

条目格式说明见下方；写作纪律：不编数字、不编链接、不编政策文号；查不到就写查不到并标 TODO。

**新增字段 `人群`**：每条目必须标 `人群: 初中 / 高中 / 大学 / 通用` 四选一（写在 `分类:` 下面一行）。网站会自动生成"按人群找条目"目录和人群筛选项，支持 `?aud=高中` 直达链接。

## 增删改条目（三步）

**新增**：复制 `entries/LS-001.md` 为新文件（如 `LS-004.md`），改 frontmatter 和正文字段。
**修改**：直接编辑对应文件。
**删除**：删掉对应文件。

然后：

```bash
python3 build.py          # 重新生成 index.html
git add -A && git commit -m "更新条目" && git push
```

推送后 GitHub Pages 自动更新，无需其他操作。

## 条目文件格式

```markdown
---
编号: LS-004
标题: 动词开头，一句话说清动作
分类: 选科 / 志愿填报 / 复读 / 专业选择 / 升学路径 / 学习方法 / 政策解读
日期: 2026-09-28
数据截至: 如"2026 年浙江投档线"
钱: "0" / 少 / 多          # 0=不花钱，少=千元级，多=万元级
时间: 少 / 中 / 多          # 少=小时天级，中=周月级，多=学期年级
精力: 否 / 些 / 是
收益量级: 大 / 中 / 小
证据等级: A / B / C        # A=官方数据，B=机构数据，C=从业经验；可写"A；TODO …"
性价比: 极高 / 高 / 一般    # 这是判断，只算 C 级
---

- 成本：…
- 说人话：一句话结论，家长一遍读懂
- 收益：分"分数与录取 / 时间 / 金钱 / 选择权与风险"四口径写
- 证据等级：…
- 来源：原始出处；没有就不写，不编链接
- 备注：适用人群、例外、政策变动提醒
- 性价比：…
```

写作纪律：不编数字、不编链接、不编政策文号；查不到就写查不到并标 TODO；
分数线、政策带截至日期，加一句"请以官方最新公布为准"。
